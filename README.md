# Project X2010

> Bringing the original Windows Phone 7 Xbox Hub experience back to Android.

## 📱 About

Welcome to **Project X2010**, the very first project in the **MetroOA (Metro On Android)** series.

Project X2010 is a fan-made Android application that recreates the iconic **Xbox Hub** from the original **Windows Phone 7 (2010)** era. The goal of this project is to preserve and revive the beautiful Metro design language that made Windows Phone unique.

Inspired by Microsoft's original Metro interface, this app brings back the classic Xbox experience with authentic typography, layouts, animations, and design elements that defined the early days of Windows Phone.

## ✨ Features

- Classic Windows Phone 7 Xbox Hub design
- Metro UI-inspired navigation
- Recreated typography and visual style
- Lightweight and mobile-friendly
- Designed for nostalgia and preservation
- Open-source source code

## 🎯 Project Goal

This project is not intended to be an official Microsoft product.

The purpose of Project X2010 is to:

- Preserve the Windows Phone design legacy
- Demonstrate Metro UI concepts on Android
- Allow fans to experience the classic Xbox Hub again
- Practice mobile UI development and recreation techniques
